# 🤟 ISL Vision Pro - Real-Time Indian Sign Language AI

An intelligent, real-time Indian Sign Language (ISL) recognition and speech synthesis platform.

## Features
- **Participant Onboarding**: Full Name, Age, Country, Phone Number registration gate with persistent HUD display.
- **Real-Time Landmark Tracking**: MediaPipe Hands with wrist-relative 63-keypoint normalization.
- **Deep Learning Classifier**: Neural network trained on ISL gestures and digits.
- **Speech Synthesis System**: In-browser Web Speech API audio synthesis with mute, volume, rate, and pitch controls.
- **Interactive Transcription Desk**: Live sentence builder with copy, download, and read-aloud functionality.
